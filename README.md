# 🏆 SDT Kalani College – Sports Management System

A complete static HTML website for SDT Kalani College of Arts, Commerce & Science, Kalyan.

## Pages
- `index.html` – Homepage with college building image, about, vision/mission
- `about.html` – About the sports department
- `event.html` – All sports events with registration links
- `gallery.html` – Sports photo gallery with lightbox
- `circular.html` – Notices and circulars
- `contact.html` – Contact form and details

## Run Locally (Windows)
Just **double-click `index.html`** in File Explorer — opens in your browser instantly!  
No Python, no server, no installation needed.

## Host FREE on GitHub Pages (Recommended)
1. Create a GitHub account at github.com
2. Create a new **public** repository named `sdt-sports`
3. Upload all files from this folder
4. Go to Settings → Pages → Source: **main branch / root**
5. Your site is live at: `https://yourusername.github.io/sdt-sports`

## Host FREE on Netlify (Alternative)
1. Go to netlify.com → Sign up free
2. Drag and drop this entire folder onto the Netlify dashboard
3. Done — live in 30 seconds!

> **No server errors** — This is a pure static HTML site. No Flask, no Python, no database. Works 100% on any free hosting platform.
